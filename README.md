# ingT - Transport engineers
## This project was created for the Transport Engineers competition. 
<i>The topic of the competition assignment:</i> Development of a device for contactless detection of passenger emotions in a room for additional inspection
### The project consists of:
* A part executed on a computer (non-network face recognition)
* Video surveillance devices (cameras)
#### The project can also be used with video surveillance cameras.
